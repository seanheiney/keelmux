---
name: bounded-review
description: Review a supplied change against its stated scope and report source-linked findings.
---

Use this skill when the user asks for a bounded source review.

1. Read the project instructions and identify the requested files or change.
2. Read [the review checklist](checklist.md) and inspect the supplied source.
3. Report concrete findings with file and line references, or state that no finding was found within the inspected scope.
4. State what was not verified. Source inspection does not prove runtime or provider behavior.

This skill contains instructions and a text companion. It does not ask you to run programs, contact services, change credentials, or edit files.
