# The Keelmux name

Keelmux combines a steady keel with terminal multiplexing. It fits a local backplane that keeps many native agent terminals available and leaves room for later cross-server continuity.

The repository is reserved at [seanheiney/keelmux](https://github.com/seanheiney/keelmux). It was renamed while private on 2026-10-10; reservation does not establish a public release or trademark clearance.
