# Native PTY allocation investigation

The retained main-source Linux amd64 run at `4ef3c9afce086a07abd4646bd6c428abe8d43b90` failed the original eight-second slow-reader gate in 8.12 seconds and the Unicode-tail gate in 8.19 seconds. This investigation retains both tests unchanged. It introduces no production source, module pin or adopted dependency change.

An owned compiler overlay changes only `string(e.grapheme[0])` to `string(e.grapheme[:1])` inside the pinned VT parser's existing single printable ASCII byte branch. Both expressions produce the same immutable one-byte string. With Go 1.26.6 the slice expression removes the per-byte rune-string allocation. The initial Darwin race benchmark reduced 2 MiB burst allocation count from 2,097,399 to 374 and bytes from 35,807,240 to 2,263,016, but its single-run time stayed essentially equal (2.236 versus 2.265 seconds). Allocation improvement alone is not accepted throughput proof.

Baseline and overlay passed a deterministic race trace with 35,780 exact matching checkpoints. Each checkpoint includes visible/reply bytes, complete writer/reader snapshots, cells and styles, cursor and grapheme bookkeeping; the trace exercises Unicode, combining tails, charsets, insert/delete, wrap/origin modes, reset, resize and main/alternate screens. This qualifies valid margins only. An earlier broader trace panicked identically in both variants on out-of-screen DECSTBM followed by delete-line. Its minimal 15-byte input is `ESC[2;3r ESC[2;1H ESC[M` on a 1-column, 2-row screen. The panic and earlier failed harness calls are retained with hashes in the adjacent local receipt; a separate worker owns terminal hardening.

An exact Go 1.26.6 Linux amd64 container under Colima x86 emulation crashed in the Go compiler before product execution. It does not provide Linux runtime proof. The first cleanup scan's unexpected idle QEMU spelling remains a failure; a supplemental authenticated scan records only the exact idle wrapper, with the owned container removed and independently absent. No unrelated containers were changed.

The isolated hosted workflow runs the exact base source in an owned copy with a verified pinned VT file. It compiles baseline and overlay test binaries, records three finite benchmark samples, exact trace equivalence, focused state controls and three repetitions of the unchanged eight-second gates.
